# Cuento Backend

Backend for Cuento, a roleplaying forum platform. Built with Go and Gin, backed by MySQL/MariaDB, with real-time WebSocket support and an MCP server for AI integration.

## Running locally

Requires the [cuento-frontend](https://github.com/katemakarova/cuento-frontend) to be running alongside.

```bash
docker-compose up --build
```
